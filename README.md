# みんなのIPO株

IPOの日程・必要資金・過去の初値の実績を、初心者向けに見せるサイトです。
データは `data.json` に入っていて、**毎日自動で更新**できます。

## フォルダの中身

| ファイル | 役割 |
|---|---|
| `index.html` | サイトの見た目と動き(これを開くとサイトが表示されます) |
| `data.json` | 企業と過去のIPOのデータ(自動更新で書き換わります) |
| `scripts/update_data.py` | AIで調べて、チェックして、`data.json` を更新するプログラム |
| `.github/workflows/update.yml` | 毎日、上のプログラムを自動で動かす設定(GitHub Actions) |

## 1. まず、自分のパソコンでサイトを表示する

1. VS Code で、このフォルダを開きます(「ファイル」→「フォルダーを開く」)。
2. 拡張機能「Live Server」(作者: Ritwick Dey)を入れます。
3. `index.html` を右クリックして「Open with Live Server」を選びます。

※ `index.html` をダブルクリックして開くと、`data.json` を読めず、エラーの表示になります。必ずLive Serverなどで開いてください。

## 2. 自動更新を自分のパソコンで試す(任意)

Python(3.10以上)が必要です。

```
pip install -r scripts/requirements.txt
```

APIキー(Anthropicの「Console」で作れます)を、環境変数に入れます。

- Windows(PowerShell): `$env:ANTHROPIC_API_KEY = "自分のAPIキー"`
- Mac / Linux: `export ANTHROPIC_API_KEY="自分のAPIキー"`

まず「保存しない試運転」をします。

```
python scripts/update_data.py --dry-run
```

調べた結果と、変わる内容が表示されます。問題なければ、`--dry-run` を付けずに実行すると、`data.json` が更新されます。

> APIキーは、ファイルに書かない・チャットに貼らない・GitHubにアップロードしない。これだけは守ってください。

## 3. 毎日、自動で更新する(GitHub + GitHub Actions)

1. GitHubのアカウントを作り、新しいリポジトリを作ります。
2. このフォルダの中身を、リポジトリにアップロードします(`.env` は入れません)。
3. リポジトリの「Settings」→「Secrets and variables」→「Actions」→「New repository secret」で、
   名前を `ANTHROPIC_API_KEY`、値をAPIキーにして保存します。
4. 「Actions」タブを開き、「IPOデータを毎日更新」→「Run workflow」で、まず手動で1回動かします。
   成功すると、`data.json` が更新されます(変更がなければ、何も起きません)。
5. 以後、毎日朝7時(日本時間)ごろに、自動で動きます。

### サイトをインターネットに公開する(GitHub Pages)

リポジトリの「Settings」→「Pages」で、公開するブランチ(`main`)とフォルダ(`/ (root)`)を選びます。
`data.json` が更新されると、サイトにも自動で反映されます。

## 安全のしくみ

- APIキーは、GitHubの「Secrets」にだけ置きます。サイト(ブラウザ側のコード)には入りません。
- AIの答えは、そのまま保存されません。日付の順番、価格が仮条件の範囲内か、証券コードの形式、
  初値の騰落率が異常でないか、URLが `https` か、などを確認します。
- AIの文章は、危険な文字(`<` `>` など)を無害な形に直してから保存します。
- チェックに通らなかった日は、`data.json` を変更せず、理由を表示して止まります(Actionsの画面で確認できます)。
- 企業数が急に減った場合も、調べ方の失敗とみなして、反映しません。

## 注意

- **AIの調べものは、間違えることがあります。** 最初のうちは、更新のたびに、`data.json` の変更内容(GitHubの「Commits」)を見て、
  JPXの資料や証券会社の案内と合っているか、確認することをおすすめします。
- APIの利用には、料金がかかります(Web検索を使うため、1回ごとに数十円〜数百円程度かかることがあります。実際の金額は、Consoleの利用状況で確認してください)。
  料金の上限は、Consoleの設定で決められます。
- 他のサイトの情報を使う場合は、各サイトの利用規約を確認してください。このプログラムは、AIに公式の資料(JPXなど)を優先して調べるよう指示しています。
- このサイトは、投資の助言ではありません。
- 強みとリスクの解説や、売上のグラフは、まだ自動化していません(目論見書の確認が必要なため)。

## うまくいかないとき

- 「anthropic が入っていません」→ `pip install -r scripts/requirements.txt` を実行します。
- 「ANTHROPIC_API_KEY が設定されていません」→ 環境変数(またはGitHubのSecrets)を確認します。
- 「チェックに通らなかった」→ 表示された理由を確認します。多くは、AIが見つけた数字が不自然だったときです。もう一度実行すると直ることがあります。
- 検索の機能の名前が変わって動かない場合は、環境変数 `IPO_SEARCH_TOOL` に、最新のWeb検索ツールの名前を入れてください(Anthropicの公式ドキュメントで確認できます)。
